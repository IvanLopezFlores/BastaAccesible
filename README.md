# BastaAccesible

**BastaAccesible** es una adaptación web del juego tradicional *Basta*, diseñada para favorecer una interacción más accesible mediante voz, teclado y controles simples.

El proyecto fue desarrollado como una exploración de las posibilidades de la programación para adaptar actividades lúdicas a distintos modos de interacción.

## Objetivo

El propósito principal es ofrecer una versión del juego que pueda utilizarse sin depender exclusivamente de la interacción visual o del ratón.

La aplicación combina instrucciones visuales, síntesis de voz, temporizador y controles mediante teclado.

## Características

- Generación aleatoria de consignas.
- Selección aleatoria de letras.
- Temporizador de 10 segundos.
- Lectura de instrucciones mediante síntesis de voz.
- Controles mediante botones.
- Controles mediante teclado.
- Ejecución directa desde el navegador.
- No requiere instalación.

## Controles de teclado

- `Enter`: iniciar una nueva ronda.
- `F`: pausar el juego.
- `J`: detener la ronda y juzgar la respuesta.

Los botones visibles también permiten iniciar, pausar y reanudar el juego.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Web Speech API (`speechSynthesis`)

## Accesibilidad

El proyecto incorpora recursos de interacción mediante voz y teclado con el propósito de reducir la dependencia del ratón y de la información exclusivamente visual.

La implementación constituye una exploración educativa de accesibilidad y no pretende representar por sí sola una certificación de conformidad con estándares como WCAG.

## Uso educativo

BastaAccesible puede utilizarse para discutir temas como:

- accesibilidad en recursos educativos digitales;
- interacción mediante teclado;
- síntesis de voz;
- adaptación de juegos tradicionales;
- diseño de interfaces educativas;
- programación web aplicada a la educación.
